# LokrLab — Layout

```
LokrLab/
├── LokrLabPlugin.cs
├── LabCatalogRules.cs                      (hit tags, AOE kinds, loc stems, corrupt KV)
├── AnimatorFeelRules.cs                    (rest-delta compensation, temp group pivot, root-motion sampling)
├── CharacterLabScene.cs                    (scene transition + Host binding)
├── CharacterLabAccess.cs                   (open/close gate for other plugins)
├── CharacterLabCursorHelper.cs             (forces OS cursor visible in lab)
├── EmbeddedSceneHost.cs                    (additive load + hole crop)
├── EmbeddedSceneBinder.cs                  (Camera.rect from hole corners)
├── EmbeddedSceneHudFitter.cs               (Overlay HUD into the hole)
├── EmbeddedSceneWatchdog.cs                (retry bind if sceneLoaded was missed)
├── Sandbox/LabSandboxChrome.cs             (shared Sandbox toolbar + hole)
├── ModMenuRegistration.cs
├── Patches/
│   ├── UIMainMenuPatches.cs                (title-screen Mods button)
│   ├── EmbeddedSceneAspectPatch.cs         (do not reset Camera.rect)
│   ├── EmbeddedSceneInputPatch.cs          (lab chrome over hole is not UI; keep fight Icons)
│   ├── EmbeddedSceneHexGridPatch.cs        (parent HexGridRoot under the fight board)
│   └── EmbeddedSceneCameraBasePatch.cs     (hole camera + unclamp / zoom range)
├── Shared/
│   ├── LabSlugIds.cs                       (legalize slug + mint 6-char token)
│   ├── LabSlugCreateFields.cs              (Name / Slug / Alias / Auto / id preview)
│   ├── LabClipboard.cs                     (Copy unique id to the clipboard)
│   └── LabAliasesInspector.cs              (aliases.json list in the inspector)
├── Shell/
│   ├── ProjectMarker.cs                    (project.json read/write)
│   ├── RecentProjectsStore.cs              (lab-wide recent project folders; menu shows 5)
│   ├── ProjectBrowser.cs                   (empty-state scan-and-open + New Project wizard)
│   ├── ProjectReferencePickerModal.cs      (async Choose project list)
│   ├── LabShell.cs                         (menu bar + workspaces + docks + hover info + status)
│   ├── LabHoverInfo.cs                     (hover-info strip above the status bar)
│   ├── LabMenuBar.cs                       (File/Help on Browser + shell; About)
│   ├── LabSaveUx.cs                        (dirty flag, Ctrl+S, title *, close prompt)
│   ├── NodeTreePanel.cs                    (contributors → UiTree → EditorSelection)
│   ├── FileTreePanel.cs                    (on-disk project folder)
│   └── InspectorDock.cs                    (drawers + persistent inspector hosts)
├── Character/                              (Properties / Animator / Sandbox)
├── Ability/                                (Ability Library + overlay fallback)
├── Encounter/                              (Phase 17: hero spawn points + Sandbox load)
│   ├── EncounterLabPaths.cs                (Mods/LokrLab/LokrEncounterLab/)
│   ├── EncounterFileModel.cs               (Unity-free encounter.json, schema v13 combatant source=spawn)
│   ├── EncounterExplorationRules.cs        (Unity-free pocket-aggro: hex-distance or region math)
│   ├── EncounterExploration.cs             (tracks parked pockets, wakes them on aggro)
│   ├── EncounterTriggerRules.cs            (Unity-free sparse painted trigger-region storage)
│   ├── EncounterBoardRules.cs              (Unity-free sparse walkability upsert)
│   ├── EncounterGrowRules.cs               (Unity-free live width/height clamp)
│   ├── EncounterPlacementRules.cs          (live board clamp + duplicate hex)
│   ├── EncounterTemplateRules.cs           (empty-enough arena picker names)
│   ├── EncounterPlayRules.cs               (Unity-free Sandbox start validation)
│   ├── EncounterSandbox.cs                 (live fight arm for Sandbox)
│   ├── EncounterEditRules.cs               (Unity-free click-to-place checks)
│   ├── EncounterPaintRules.cs              (Unity-free hex-line + paint clamp)
│   ├── EncounterTileRules.cs               (Unity-free sparse floor-tile overrides)
│   ├── EncounterTerrainRules.cs            (Unity-free terrain catalog upserts)
│   ├── EncounterTerrainCatalog.cs          (scan templates prefabs + resolve HexaTile)
│   ├── EncounterTiles.cs                   (Tilemap SetTile from the catalog)
│   ├── EncounterForeground.cs              (hide vanilla Paralax foliage in Lab embeds)
│   ├── EncounterPropRules.cs               (Unity-free prop instance upserts)
│   ├── EncounterPropCatalog.cs             (list/load scenario deco prefabs)
│   ├── EncounterProps.cs                   (instantiate authored props on the board)
│   ├── EncounterCatalogueRules.cs          (Unity-free name/id filter + batch math)
│   ├── EncounterCatalogueExo.cs            (load/spawn Stand exo and props)
│   ├── EncounterCatalogueThumbnails.cs     (off-screen Stand / prefab card baker)
│   ├── EncounterCataloguePreview.cs        (Stand exo / prop prefab RT preview)
│   ├── EncounterCombatantsCatalogue.cs     (persistent Combatants picker; Character/Unit only)
│   ├── EncounterPropsCatalogue.cs          (persistent Props picker)
│   ├── EncounterCatalogueDrop.cs           (drag a catalogue card onto a Setup hex)
│   ├── EncounterCameraRules.cs             (Unity-free Sandbox camera AABB + handle math)
│   ├── EncounterCamera.cs                  (apply authored limits on embed Sandbox)
│   ├── EncounterCameraGizmo.cs             (Setup world-space rect overlay)
│   ├── EncounterEdit.cs                    (armed Setup preview + drag-paint + hover ghost)
│   ├── EncounterRoster.cs                  (spawn authored combatants before StartFight)
│   ├── EncounterSession.cs                 (folder + in-memory payload)
│   ├── EncounterCreateSheet.cs             (New Project name / slug / alias)
│   ├── EncounterImportTerrainModal.cs      (import hex-art terrains from a stage)
│   ├── EncounterProjectType.cs             (Register on LokrLabApi)
│   ├── EncounterNodes.cs                   (root + Combatants + Terrains + Props + Triggers + Spawn Points + Aliases)
│   ├── EncounterSetupViewport.cs           (Setup hole + auto-load + Restart + Place / Draw Hex / Paint Terrain / Camera)
│   ├── EncounterSandboxViewport.cs         (Sandbox hole + Start / Stop)
│   └── Patches/
│       ├── EncounterEditFightEndPatch.cs   (fence CheckFightEnd while editing)
│       ├── EncounterExplorationFightEndPatch.cs (fence CheckFightEnd while a pocket is still parked)
│       ├── EncounterEditHudPatch.cs        (skip initiative / skills HUD in Setup)
│       ├── EncounterTileConstrainPatch.cs  (do not crop Lab-painted tiles)
│       ├── EncounterHexaTileSpritePatch.cs (errorSprite → hex floor sprite)
│       └── EncounterParalaxPatch.cs        (hide Paralax after Generate in embeds)
├── Placeholders/                           (character rig stub + ability templates)
└── Sidecars/                               (ability-hover.md, character-hover.md, encounter-hover.md)
```

On-disk content: `Mods/LokrLab/LokrCharacterLab/<id>/`,
`Mods/LokrLab/LokrAbilityLab/<libraryId>/`, and
`Mods/LokrLab/LokrEncounterLab/<id>/`.
